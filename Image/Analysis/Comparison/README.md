# Image Comparison Tools

This repository provides two Python scripts for comparing images using different methodologies, depending on your use case:

- **Comprehensive Image Comparison Tool** (`ImageComparissionTools.py`)
- **Statistical Image Comparison Tool** (`ImageComparissionTools_generic.py`)

---

## 1. Comprehensive Image Comparison Tool (`ImageComparissionTools.py`)

### Purpose
Performs deep, pixel-for-pixel and perceptual comparison between a reference image and one or more comparison images. **Requires images to be spatially aligned and have identical dimensions.**

## 2. Statistical Image Comparison Tool (`ImageComparissionTools_generic.py`)

### Purpose
Compares the global statistical properties of two images. It is designed for general-purpose comparison and DOES NOT require the images to be spatially aligned or have the same dimensions.
