# MBF Python REPL usage

This repository provides a number of Python scripts for short examples of how to use the MBF Python REPL available in various MBF products.

See each script for instructions on how to use the Python REPL to access image data and metadata, and to perform various operations on the data.

For a complete list of available functions and classes, see the [mbfimage module documentation] (https://github.com/MBFBioscience/MBFPythonUtilities/blob/main/Image/REPL/mbfimage.md).
